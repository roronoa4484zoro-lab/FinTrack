# FinTrack: Secure Personal Finance Assistant

## Project Overview
A secure personal finance management platform with AI-driven insights.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database**: PostgreSQL (Supabase)
- **Authentication**: JWT + HTTP-only Cookies
- **AI**: LLM via API (OpenAI/Claude)

## Project Structure
- `src/app/api`: Backend API endpoints
- `src/app/dashboard`: User dashboard views
- `src/components`: Reusable UI components
- `src/lib`: Utility functions, DB client, and security helpers
- `src/types`: TypeScript interfaces
